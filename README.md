### Counterfactual Offline Policy Learning

Offline RL is bottlenecked by **dataset coverage**.  
**CoPL** keeps the real initial state, rewrites the goal into a valid **counterfactual**, and lets a grounded LLM generate the **full state–action trajectory**—then trains a standard offline policy (e.g. BC / BCQ) on real + synthetic data.

> LLM = trajectory generator &nbsp;·&nbsp; not the deployed controller

## 👤 About Me

M.S. student in **Software Engineering** @ [**SDJZU**](https://www.sdjzu.edu.cn/) (Jinan)  
B.Eng. @ [**CQUPT**](https://www.cqupt.edu.cn/) (Chongqing), **2019 – 2023**  
Advisor: **Prof. Yunan Liu** · Lab: [**CIC** Vision Group](http://www.icicconference.org/cic/)

I work on **offline reinforcement learning** for robots—how policies can still work when goals fall **outside** the demonstration distribution.  
My toolkit: grounded **LLMs / VLMs** as trajectory generators, plus ongoing work on **world models** and reward design.

🎯 **Ph.D. applicant for Fall 2028** (applications in 2027–2028).

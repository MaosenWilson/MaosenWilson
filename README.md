Graduate student at **Shandong Jianzhu University (SDJZU)**, working on **offline reinforcement learning**, **language-conditioned control**, and **vision-based world models**.  
I care about making robot policies generalize beyond the demonstration distribution—especially under **counterfactual goals** and long-horizon visual prediction.

## 🧠 Research Interests

- **Offline RL & imitation** — BC / BCQ and data-centric improvements for fixed datasets  
- **LLM × robotics** — language goals, counterfactual trajectory synthesis, grounded world models  
- **Visual world models** — temporal consistency, long-horizon prediction, diffusion-based dynamics  
- **Generalization** — ID / rephrasing / easy-CF / hard-CF style evaluation protocols
